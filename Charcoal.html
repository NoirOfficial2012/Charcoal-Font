TUTORIAL GUIDE

Embed this typeface straight into your CSS markup to get raw brutalist styling instantly. Place your file alongside your index page and call the font face rules shown here.

// Load inside your stylesheet
@font-face {
  font-family: 'Charcoal';
  src: url('./charcoal.otf') format('opentype');
  font-display: swap;
}

h1, .custom-title {
  font-family: 'Charcoal', sans-serif;
  text-transform: uppercase;
}
